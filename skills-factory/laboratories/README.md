# Skills Making Factory — Laboratories

## Purpose
The laboratories directory provides isolated testing environments for new skills, prototypes, experiments, and benchmark results. Nothing in laboratories/ is considered production-ready.

## Subdirectories

### experiments/
Experimental skills and combinations that are being tested but not yet ready for prototype stage. These are the most volatile and may change or be deleted at any time.

### prototypes/
Prototype skills that have passed initial design but are awaiting quality-control review. These are candidates for production promotion.

### failed-tests/
Skills that failed quality control, testing, or benchmarking. These are preserved for analysis and learning, not deleted.

### benchmark-results/
Benchmark results from comparative evaluations. Each skill has its own subdirectory with test results and comparison data.

## Governance
- **Nothing in laboratories is production**: Skills here cannot be used in production workflows
- **Failed tests are preserved, not deleted**: Failed skills provide learning value
- **Isolated environments**: Laboratory skills run in isolated contexts
- **No authorization needed for laboratory changes**: Laboratory files can be created and modified freely
